# Deployment Reminders

When you finish a coding task or complete a set of changes for the user, you MUST remind the user that they can deploy their changes easily using the provided batch scripts in the V6 folder. 

Always include a short reminder like this at the end of your message:

"💡 **อย่าลืม!** หากตรวจสอบโค้ดเรียบร้อยแล้ว คุณสามารถดับเบิลคลิกไฟล์ต่อไปนี้เพื่อจัดการระบบได้เลยครับ:
- `01_deploy_app.bat` (อัปเดตระบบตัวจริงขึ้นเว็บ)
- `02_deploy_maintenance.bat` (เปิดโหมดหน้าจอกำลังปรับปรุง)"
