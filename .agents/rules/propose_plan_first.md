# Propose Plan First

When the user requests the development of a new phase, feature, or complex change:
1. **Stop and Plan**: Do not immediately write code, modify files, or execute commands.
2. **Propose**: Present a clear, step-by-step plan (using bullet points or an artifact) detailing how you intend to implement the requested feature.
3. **Wait for Approval**: Explicitly ask the user if they agree with the plan or if they would like to make adjustments.
4. **Execute**: Only begin implementing the code after the user gives the go-ahead.
