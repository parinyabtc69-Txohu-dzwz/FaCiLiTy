1. บทสรุปสำหรับบอร์ดบริหาร : ทำไมต้องระบบ FaCiLiTy v1.0?

ปัญหารูปแบบเดิม (ก่อนมีระบบ)

  • • ข้อความแจ้งซ่อมตกหล่นในกลุ่ม LINE: แจ้งปนกับข้อความสนทนาอื่น ทำให้ค้นหาย้อนหลังไม่ได้ว่างานไหนทำแล้วหรือยังค้าง
  • • ผู้แจ้งไม่ทราบความคืบหน้า: คุณครูต้องเดินตามหรือโทรถามช่างเอง ไม่มีระบบแจ้งเตือนอัตโนมัติเมื่องานเสร็จ
  • • ขาดสถิติและหลักฐานประกอบการตัดสินใจ: ไม่มีรายงานสรุป KPI รายเดือน รูปก่อน-หลังซ่อม หรือประวัติใบเสร็จค่าวัสดุ

ทางออกด้วย FaCiLiTy v1.0 (Smart Resource Hub)

  • ✓ รวมศูนย์ 5 บริการในแอปเดียว: ซ่อมอาคาร, ซ่อมไอที, ซ่อมโสตฯ, ยืม-คืนอุปกรณ์โสตฯ และเสนอโครงการจัดซื้อระยะยาว
  • ✓ แจ้งเตือนแยกตามบทบาท (Role-Based Push): เตือนเฉพาะผู้เกี่ยวข้อง ไม่รบกวนครูท่านอื่น พร้อมห้องแชทคุยกับช่างในใบงาน
  • ✓ งบประมาณดูแลระบบ 0 บาท/ปี (Zero Server Cost): พัฒนาบน Google Workspace & Firebase Cloud มาตรฐานองค์กร

1

กรณีคลิกลิงก์มาจากแอป LINE: ระบบจะเด้งออกจาก LINE หรือแสดงกล่องสีเหลือง ให้กดปุ่ม "กดเพื่อเปิดใน Safari / Chrome ทันที" ก่อน เพื่อให้ Google อนุญาตให้ล็อกอินได้

2

กดปุ่ม `เข้าสู่ระบบด้วย Google`: เลือกบัญชี Gmail ของคุณครู ระบบจะดึงชื่อ-นามสกุลและอีเมลมาผูกสิทธิ์ให้อัตโนมัติ (เข้าครั้งแรกได้สิทธิ์ `Teacher` ทันที)

3

ปุ่มสีเขียว `เข้าร่วมกลุ่ม LINE แจ้งเตือน`: สำหรับทีมช่างและเจ้าหน้าที่ที่ต้องการเข้ากลุ่ม LINE รวมของโรงเรียน

วิธีติดตั้งแอปบน iPhone / iPad (Safari)

  1. 1. เปิดเว็บใน Safari แล้วแตะปุ่ม "แชร์" (Share) ด้านล่างจอ
  2. 2. เลื่อนลงมาเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  3. 3. แตะปุ่ม "เพิ่ม" (Add) มุมขวาบน จะได้ไอคอนแอป FaCiLiTy บนหน้าจอมือถือทันที!

วิธีติดตั้งแอปบน Android / คอมพิวเตอร์ (Chrome)

  1. 1. กดปุ่มสีเขียว "ติดตั้งแอป" บนแถบด้านบนของหน้าเว็บ (หรือเมนูด้านซ้ายล่าง)
  2. 2. จะมีหน้าต่างเด้งขึ้นมาถาม ให้กดยืนยัน "ติดตั้ง" (Install)
  3. 3. แอปจะถูกติดตั้งลงเครื่อง เปิดใช้งานเต็มจอและรับเสียงเตือนได้เหมือนแอปทั่วไป
หมายเหตุสำหรับ iPhone/iPad: ต้องเพิ่มแอปลงหน้าจอโฮมก่อน จึงจะกดเปิดรับการแจ้งเตือนแบบเด้งบนหน้าจอล็อกได้ FaCiLiTy v1.0 — Authentication & PWA Setup

การแนบรูปผลงานหลังซ่อมเสร็จ & รูปใบเสร็จค่าวัสดุ

ช่างถ่ายรูปหลังซ่อมเสร็จและแนบใบเสร็จค่าอะไหล่ (ถ้ามี) ระบบบันทึกลิงก์รูปลง Google Sheets และ Google Drive แยกโฟลเดอร์อัตโนมัติ

4

เมนูตั้งค่าระบบสำหรับแอดมิน (`จัดการผู้ใช้`, `Master Data`, `จัดการบั๊ก`)

กำหนดโรลผู้ใช้ (`Teacher`, `Tech`, `AV`, `Executive`, `Admin`), เพิ่มรายชื่ออาคาร/ห้อง/อุปกรณ์โสตฯ และกดรันเลขคิวใหม่ (`#01`) ได้จากหน้าเว็บ

ตารางสรุปการแยกแจ้งเตือนตามบทบาท (Role-Based Push v1.0)

ไม่รบกวนข้ามแผนก
บทบาท (Role) สิ่งที่ได้รับแจ้งเตือน (ในแอป + จอล็อกมือถือ)
👩‍🏫 ครู / บุคลากร
(Teacher)		 รับเฉพาะ ใบงานของตนเอง (เมื่อช่างรับงาน, อัปเดตสถานะ, ซ่อมเสร็จ หรือทักแชท) ไม่เด้งเตือนงานของครูท่านอื่น
🔧 ช่างอาคาร / ไอที
(Tech)		 รับแจ้งเตือนเมื่อมี ใบแจ้งซ่อมอาคาร / ไอทีเข้าใหม่, งานที่ได้รับมอบหมาย, แชทจากผู้แจ้ง และเมื่อถูกแอดมินกดสะกิดเตือน
🎙️ โสตทัศนศึกษา
(AV)		 รับแจ้งเตือนเฉพาะ คำขอยืม-คืนอุปกรณ์โสตฯ และ ใบแจ้งซ่อมอุปกรณ์โสตฯ
👔 ผู้บริหาร
(Executive)		 รับแจ้งเตือนเมื่อมี การเสนอโครงการระยะยาว / จัดซื้อใหม่ ที่รอการอนุมัติ และงานที่ผู้บริหารเป็นผู้แจ้งเอง
🛡️ ผู้ดูแลระบบ
(Admin)		 รับแจ้งเตือน ทุกความเคลื่อนไหวในระบบ + เห็นปุ่ม ยิงทดสอบเตือน / ทดสอบ LINE แต่เพียงผู้เดียว
